# SinaiTelegram private widget

This bundle deliberately contains no Telegram or business logic. Its sole capability is `lead_sources`, required by amoCRM before the backend may manage multiple sources.

Before uploading, confirm in amoCRM whether the private-integration form assigns a widget code. If it does, keep that generated code as the widget code and provide it to amoCRM Support for the `SinaiTelegram` Chats Channel. Do not put OAuth secrets in this archive.
